# 生活助理（VoiceAssistant）

说一句话，自动变成日程。

一个面向个人的安卓语音日程助手：按住说话 → 语音转文字 → AI 解析成结构化行程 → 写入本地日历 → 到点提醒。

> **当前状态：可用。** 「按住说话 → 本地识别 → AI 解析 → 存入日历 → 到点提醒」整条链路已经跑通，
> 支持全天行程、定期行程、编辑删除与手动录入。功能清单与技术选型见 [生活助理开发规划.md](./生活助理开发规划.md)。

---

## 为什么做这个

记一条日程本该很简单，但打开日历、点新建、选日期、选时间、填标题、设提醒，一套下来半分钟就没了。这个项目想做的事很朴素：**说一句话就够了**。

「明天下午三点开项目评审会」——说完，日程就建好了。

项目为个人自用而做，开源出来是因为想法不复杂，代码也不复杂，希望能给别人一点参考。

## 功能

| 功能 | 说明 |
| --- | --- |
| 语音录入 | 按住说话，**设备端离线识别**：不联网、无时长限制、音频不出手机 |
| AI 解析 | 调用 DeepSeek 把自然语言转成结构化行程 |
| 结果确认 | 展示解析结果后再保存，识别文字可修改 |
| 月视图日历 | 按月展示，全天与定时行程同格混排，可点选任意日期 |
| 全天行程 | 支持「下周三请一天假」，按日期存储，不受时区影响 |
| 本地存储 | 行程、重复规则、提醒三类数据存本地数据库 |
| 分类提醒 | 按急迫性预设提前量（15 分钟 ~ 2 天），也可自行调整 |
| 定期行程 | 每日、每周（可指定周几、可设结束日期），提醒按规则预注册 |
| 行程管理 | 语音新建、手动新建、编辑、删除 |
| 设置中心 | DeepSeek、语音模型、时间选择方式、每周起始日、深色模式、提醒权限、数据备份 |
| 改进意见 | 想到什么随手记一句；连上电脑后直接读走，不需要手动同步 |
| 数据备份 | 一键把行程、重复规则、提醒与改进意见导成一份 JSON（落到下载目录或另存到别处），也能从这样一份备份里恢复：没有的加进来、删掉的找回来；不含 API Key |
| 冲突提示 | 保存前若与已有行程撞时间，先列出来问一句；全天与定时行程互不算冲突 |
| 急迫程度 | 分紧急 / 常规 / 不急三档，日历、列表、详情用同一套颜色标注；AI 解析会给出，手动录入可自己改 |
| 桌面小组件 | 桌面上的「今天」：今天的行程一眼看完，点一行直接跳到那条行程 |

暂不支持（后续可能做）：账号与云同步、系统日历同步、每月/每年/农历等复杂重复规则、
语音播报、自动避开冲突的「另找时间」建议。

## 桌面小组件

桌面上的「生活助理 · 今天」把当天的行程摊在眼前，不用先打开应用：

- 一行一条行程，左边那根小竖条是急迫程度（红 / 蓝 / 灰），与应用里是同一套颜色；
- **点标题**进应用，**点某一行**直接跳到那条行程的详情，**点右上角的小话筒**直接开始说话；
- 一屏放不下时下面写「还有 N 条」，点它也进应用；
- 今天没有安排时，顺带说一句未来一周里的下一次是什么时候；
- 横竖都能拉；能放几行是按你拉完的高度算出来的，不会裁掉半行。

添加方式：**长按桌面空白处 → 小组件 → 找到「生活助理 · 今天」→ 拖到桌面上**。

> 小米 / 澎湃（HyperOS）上要多走一步：长按桌面 → 添加小部件之后，先看**列表最下面的
> 「安卓小部件」**——第三方应用的普通小部件都收在那里（上面那一栏列的是小米自己适配过的应用）。
> 其他品牌的桌面一般直接在应用列表里就能找到。

更新时机有两处：行程**增删改之后立刻重画**（不管是在应用里改的，还是恢复了备份）；
另外每半小时自己对一次表，所以过了零点会自动换成新的一天。小组件不额外申请任何权限。

> 深色模式下小组件跟着**系统**走。应用里「设置 → 深色模式」选的那一档只影响应用界面本身——
> 桌面小组件由启动器渲染，读不到应用自己的主题设置。

## 技术栈

- **语言与界面**：Kotlin + Jetpack Compose（Material 3）
- **架构**：UI / ViewModel / 业务用例 / 数据层 的轻量分层
- **本地存储**：Room（SQLite）+ KSP
- **网络**：系统 `HttpURLConnection` + `org.json`（只有一个接口要调，不引入第三方网络库）
- **提醒**：AlarmManager + NotificationManager（本地通知）
- **语音识别**：sherpa-onnx + Paraformer 中文模型，完全在设备端运行
- **AI 解析**：DeepSeek API（`deepseek-chat` / `deepseek-reasoner`）

## 代码结构

```text
app/src/main/java/io/github/xfl2342/voiceassistant/
├── ai/         DeepSeek 调用、提示词、解析结果模型
├── data/       数据库（Room）、设置存储、API Key 加密、备份的读写
├── domain/     业务规则：重复规则展开、提醒计划、草稿转实体
├── reminder/   系统闹钟注册、通知、开机恢复
├── speech/     设备端离线识别引擎与录音
├── widget/     桌面小组件：今天的行程
└── ui/         界面：日历、录音、详情、编辑、设置
```

工程里还有 `tools/`，放的是电脑这边用的小脚本（目前只有取回改进意见那一个）。

单元测试在 `app/src/test/`，覆盖重复规则展开、草稿转换、冲突判断、备份文件格式与小组件排版
这五处最容易算错的逻辑；
需要真机才能验的部分在 `app/src/androidTest/`（比如意见与备份到底有没有写进下载目录、
文件能不能当 JSON 读回来、删掉的行程能不能靠一份备份找回来）。

> 工程路径含中文时，单元测试任务会因为 Java 读取参数文件的编码问题失败（报 `ClassNotFoundException`）。
> 把工程放到纯英文路径即可，或复制一份到英文路径下再跑。

## 构建与运行

1. 用 Android Studio 打开本项目根目录；
2. 首次打开会自动同步 Gradle 依赖，等待完成；
3. 连接安卓手机（需开启「开发者选项 → USB 调试」）或启动模拟器；
4. 点击 Run 安装到设备。

命令行构建需要先在根目录创建 `local.properties`（Android Studio 会自动生成，无需手动创建）：

```properties
sdk.dir=/path/to/Android/Sdk
```

Windows 路径中的反斜杠需要转义，例如：

```properties
sdk.dir=C\:\\Users\\<用户名>\\AppData\\Local\\Android\\Sdk
```

## 配置 AI 解析

**本项目不提供 API Key，需要你自备。**

1. 到 [DeepSeek 开放平台](https://platform.deepseek.com/) 注册并充值，创建一个 API Key；
2. 打开 App → 设置 → DeepSeek，填入 API Key；
3. 点击「测试连接」确认可用。

Key 只保存在你自己的手机上（经系统密钥库加密存储），**不会上传到任何第三方服务器**；App 直接向 DeepSeek 官方接口发起请求。

> 请勿把 API Key 写进代码或提交到仓库。仓库的 `.gitignore` 已覆盖常见的密钥文件名，但仍需你自己留意。

## 安装语音模型

语音识别用的是设备端模型（约 74 MB），**不随安装包发布**，首次使用前需要安装一次。装好之后识别完全在手机本地进行：不需要网络，没有时长限制，音频不出手机。

模型文件：`sherpa-onnx-paraformer-zh-small-2024-03-09.tar.bz2`

下载地址：[k2-fsa/sherpa-onnx 发布页](https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-paraformer-zh-small-2024-03-09.tar.bz2)

两种安装方式，任选其一：

1. **应用内下载**：设置 → 语音模型 → 下载模型。直接从上面的地址下载，网络通畅时最省事。
2. **从文件安装**：先在电脑上下载上面的压缩包，传到手机（数据线、网盘都行），然后在 设置 → 语音模型 → 从文件安装 里选中它。这条路不依赖手机的网络环境。

> 国内网络访问 GitHub 常常不通，此时用第二种方式。
>
> 模型不需要频繁更新。除非识别准确率让你不满意，或者出现了更小更快的新版本，否则装一次就可以一直用。

## 记录改进意见（手机上记，电脑上读）

用着用着觉得哪里别扭，不必当场想清楚：**设置 → 改进意见**里写一句就行，回头连电脑时一起改。

- 每记一条（编辑、删除、标记完成也算），应用都会把**全部**意见重新写一份到手机的下载目录：
  `内部存储 → Download → 生活助理-改进意见.md`。所以这份文件一直是最新的，不靠人记得去点「导出」；
- 用数据线连上电脑后，这个文件在 Windows 资源管理器里直接可见，拷出来就能看（Windows 上手机存储一般显示为「内部存储」）；
- 也可以让电脑上的 Codex 直接取：

  ```powershell
  powershell -ExecutionPolicy Bypass -File tools\pull-feedback.ps1
  ```

  脚本会把文件取到工程根目录的 `改进意见.md`（已在 `.gitignore` 里，不会被提交），并把内容打印出来。

写的时候一条只写一件事，顺带说清楚「在哪、怎么别扭、希望变成什么样」，改起来最快，例如：
「日历首页看不到天气，希望每天格子里带个小图标」。

## 备份与恢复（换手机、手滑删了的时候用）

**设置 → 数据备份**，按一下「导出到下载目录」，全部数据会写成一份 JSON：

```text
内部存储 → Download → 生活助理-备份-2026-09-26-153000.json
```

- 里面是行程、重复规则、提醒与改进意见，字段名和数据库保持一致，换台手机也看得懂；
- **每次导出都是新的一份**，文件名带导出时间，不会覆盖上一次的备份；
- 导出只是把数据库读一遍，不改动任何数据；写失败也就是少一份文件，行程不会丢；
- **不含 API Key**，也不含深色模式、时间方式这些设置；已经删掉的行程不会进去；
- 想直接存进网盘、U 盘，用旁边的「另存为」自己挑位置。

同一页往下翻，用「选择备份文件…」挑一份以前导出的备份，就能把里面的东西读回来。

恢复**只增不减**，三条规则说清楚：

- 手机上没有的行程：加进来；
- 之前删掉的行程：找回来（删除只是打了个标记，行还在库里，所以能原样救回）；
- 手机上已有的同一条：跳过，不覆盖——你在手机上改过的东西，不该被一份旧备份盖回去。

所以恢复之前不需要先清空数据，同一份备份导入两次也不会变成两条。确认之前，会先把
「新增几条、找回几条、跳过几条」摆出来给你看一眼；恢复完，提醒会按行程重新排一遍闹钟。

> 换手机之后要注意：**API Key 与各项设置不在备份里**，需要重新填一次。这是刻意的——
> 备份文件是用来传数据的，不该夹带密钥。

## 隐私说明

- **语音**：录音用于语音识别，不保存原始音频文件（除非你手动开启该选项）；
- **行程数据**：全部保存在本机数据库，不上传、不同步到云端；备份文件由你自己发起导出，存到哪由你决定（默认下载目录），里面不含 API Key；
- **改进意见**：同上，只在本机数据库，外加一份写到手机下载目录的 Markdown（给数据线连接时读，不联网）；
- **发给 AI 的内容**：仅包含语音识别后的文字，用于解析成行程结构；
- **无账号体系**：App 不需要注册登录，也没有任何埋点与统计。

## 已知限制

- **不能放在中文路径下**（Windows）：安卓构建工具默认拒绝中文路径，本项目已用开关绕过，
  编译打包正常；但 **Gradle 单元测试任务仍会失败**，详见「常见问题」。放到纯英文路径可彻底避免；
- **语音模型**：识别模型约 74 MB，不随安装包发布，需要单独安装一次，详见「安装语音模型」；
- **提醒准时性**：国产 ROM 的后台管理较严格，需要手动开启「自启动」「省电策略设为无限制」，并在多任务界面锁定应用，否则提醒可能延迟或丢失；
- **重复规则**：目前只支持每日、每周，不支持每月、每年、农历与节假日跳过；
- **备份**：恢复只增不减，不会覆盖手机上已有的同一条行程；备份里不含 API Key 与外观、
  时间方式这些设置，换机后要重新填一次 Key；
- **平台**：仅支持安卓，暂无 iOS 计划。

## 常见问题

**单元测试跑不起来，报 `ClassNotFoundException`**

如果工程放在含中文的路径下（Windows），就会出现这个现象。原因是：Gradle 以 UTF-8 写出
测试进程的参数文件，而 Windows 版 Java 默认按系统本地编码（简体中文环境是 GBK）去读它，
中文路径被解析成乱码，于是测试类「找不到」。

把工程移动到纯英文路径即可彻底解决。需要注意的是，在中文路径下**编译、打包、安装到手机
都不受影响**，只有单元测试会失败。

**依赖下载很慢或长时间卡住**

直连 Maven Central 在国内经常出现 TLS 握手被中断、长时间无响应。可以给 Gradle 配一份本机
镜像，把依赖源指向国内站点。这个配置放在 `%USERPROFILE%\.gradle\init.d\` 目录下，
只对本机生效，不会写进工程，也不影响别人克隆你的代码。

## English

**VoiceAssistant** — an Android voice-driven calendar for personal use. Speak a sentence like "meeting at 3 pm tomorrow, remind me 15 minutes earlier", and the app transcribes it, uses the DeepSeek API to parse it into a structured event, stores it locally, and fires a local notification on time.

Built with Kotlin + Jetpack Compose, Room, and AlarmManager. All data stays on your device; you need to bring your own DeepSeek API key.

**Status:** planning stage — only the design document exists so far.
